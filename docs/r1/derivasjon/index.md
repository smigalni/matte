# R1 – Derivasjon

Kapittel 3 handler om vekstfart, tangenter og derivasjon. Start med **3.1 Vekstfart og tangent**, og arbeid deretter videre med reglene og anvendelsene.

## Læringsløp

1. **3.1 Vekstfart og tangent** – gjennomsnittlig og momentan vekstfart, tangentens stigningstall og tangentlikning.
2. **3.2 Vanlige derivasjonsregler** – deriver polynomer, eksponential- og logaritmefunksjoner.
3. **3.3 Kjerneregelen** – deriver sammensatte funksjoner.
4. **3.4 Produktregelen og kvotientregelen** – deriver produkter og brøker.
5. **3.5 Deriverbarhet** – undersøk kontinuitet og ensidige deriverte.
6. **3.6 Definisjonen av den deriverte** – forstå grenseverdien bak derivasjon.
7. **3.7 Numerisk derivasjon** – tilnærm den deriverte og vurder feilkilder.
8. **3.8 Programmering** – utforsk deriverte numerisk og modeller bevegelse.
9. **3.9 Blandede oppgaver** – tren på å velge metode på tvers av delkapitlene.
10. **3.10 Kapittelprøve** – krevende oppgaver i Del 1 og Del 2.

## Slik arbeider du

- Les forklaringen og følg eksemplene steg for steg.
- Løs oppgavene uten å se på fasiten først.
- Vis mellomregning, skriv hvilken regel du bruker, og forklar hva svaret betyr.
- I utfordringsoppgavene forventes det at du velger metode selv og begrunner konklusjonen.
